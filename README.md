# Learning Archive

A collection of early coding exercises, small programs, and experiments written while learning web development. This repo spans several languages and frameworks and reflects a range of skill levels as concepts were being picked up over time.

> Note: This repo was previously named `projects`. It's been renamed and archived to reflect its role as a historical record rather than active work.

## 📂 What's Inside

| Folder | Description |
|---|---|
| `c` | Simple C programs |
| `css` | CSS exercises and layout experiments |
| `drobely` | Miscellaneous project |
| `eloquent-javascript` | Exercises following *Eloquent JavaScript* |
| `front-end` | General front-end/flex layout markup |
| `javascript` | Vanilla JavaScript exercises |
| `node/jwt-auth-nodejs` | Node.js JWT authentication example |
| `php` | Legacy procedural and OOP PHP scripts |
| `svg-projects` | SVG and Sass exercises |
| `vuejs` | Vue.js exercises and small apps |

Root-level files (`index.html`, `package.json`, etc.) support a few of the standalone exercises directly.

## 🛠️ Languages Used

Mostly HTML, with some JavaScript, PHP, and Vue mixed in throughout.

## 📌 Purpose

This is not a production codebase — it's a personal archive of learning exercises, tutorials followed, and small experiments from earlier in my development journey. Code quality and conventions vary by folder and reflect where I was at the time.
